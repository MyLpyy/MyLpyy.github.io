## 2. Fonction de l’extension

L’extension permet à l’utilisateur de demander une explication
d’une question affichée sur Socrative.

L’analyse est déclenchée lorsque l’utilisateur clique sur
« Analyser la question ».

## 3. Données traitées

Pour réaliser cette analyse, l’extension lit dans la page active :

- le texte de la question ;
- les choix de réponse disponibles.

Ces textes peuvent contenir des données personnelles si de telles
informations figurent dans l’énoncé ou dans les choix de réponse.

L’extension traite également la réponse générée par l’intelligence
artificielle et les informations techniques nécessaires au diagnostic :
sélecteurs utilisés, nombre d’éléments trouvés, prompt, modèle,
réponse de l’API et messages d’erreur, selon les informations
disponibles dans la version utilisée.

L’extension n’est pas conçue pour collecter les mots de passe,
les cookies de connexion, les noms de salle ou l’historique
général de navigation.

## 4. Transmission à Google Gemini

Le texte extrait et les instructions d’analyse sont transmis,
via une connexion HTTPS, au service Google Gemini API afin
de générer une réponse.

Les appels sont adressés au domaine :
generativelanguage.googleapis.com.

Le fournisseur reçoit également les informations techniques
inhérentes à une connexion réseau, notamment l’adresse IP
depuis laquelle la requête est effectuée.

Le traitement, la conservation et l’utilisation des données
par Google dépendent des conditions applicables au service
Gemini API et à l’offre utilisée.

Consultez notamment :
https://ai.google.dev/gemini-api/terms
https://policies.google.com/privacy

N’envoyez pas d’informations personnelles, confidentielles
ou sensibles dans les questions analysées.

## 5. Conservation et diagnostic

Dans la version décrite ici, l’extension ne crée pas de base
de données ni d’historique persistant des analyses.

Le panneau conserve temporairement en mémoire des informations
sur la dernière analyse pour permettre leur affichage avec
la fonction « Debug ».

L’éditeur ne reçoit pas automatiquement ces informations
et n’exploite pas de serveur intermédiaire pour les analyses.

Si l’utilisateur transmet volontairement un rapport de debug
à l’éditeur pour obtenir de l’aide, ce rapport peut contenir
la question, les choix et la réponse de l’IA. Il doit vérifier
et supprimer les informations sensibles avant de l’envoyer.

Ces dispositions ne déterminent pas la durée de conservation
des données par Google, qui relève des conditions de son service.

## 6. Utilisation et partage

Les données sont utilisées pour fournir l’analyse demandée
et permettre le diagnostic de son fonctionnement.

L’éditeur ne vend pas ces données et ne les utilise pas
à des fins de publicité ou de profilage publicitaire.

L’utilisation des données est limitée à la finalité déclarée
de l’extension et respecte les règles relatives aux données
utilisateur du Chrome Web Store, notamment les exigences
de « Limited Use ».

## 7. Choix de l’utilisateur

L’utilisateur peut éviter toute nouvelle analyse en ne cliquant
pas sur le bouton « Analyser la question », ou en désactivant
ou désinstallant l’extension.

La désinstallation ne supprime pas nécessairement les données
déjà transmises à Google. Les demandes concernant ces données
relèvent des procédures et conditions du fournisseur.

Pour les données éventuellement envoyées directement à l’éditeur
dans une demande d’assistance, contactez :
[ADRESSE E-MAIL DE CONTACT].

## 8. Modifications

Cette politique sera actualisée en cas de modification

des données.
